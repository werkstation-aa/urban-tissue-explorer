Origins & destinations

Entrances are 1 ha cell centres, each attached to the nearest street within EntDist (SNAPy's default is 100 m). Cells further from any street are left out. POI destinations are weighted by the number of POIs in the cell; floor area needs building heights (Setup tab).

Analyses

m
What the parameters do
  1. SearchDist: network distance limit for every analysis (SNAPy's defaults are 1,200 m, and 1,500 m for Straightness).
  2. CalcExp weights destinations by distance for Reach (WD) and Straightness. Below 0: inverse-distance decay eβ·d/R·(1 − d/R). 0: linear (Reach) or unweighted (Straightness). Above 0: farther destinations count more.
  3. CalcComp (Reach WD): the k-th nearest destination is multiplied by CalcCompk, so each extra destination adds less.
  4. AlphaExp (Betweenness): each origin splits its weight across reachable destinations in proportion to weight × (Dmin/d)1+AlphaExp; higher values favour nearer destinations.
  5. SNAPy's DetourR multi-path option isn't ported. Movement follows shortest paths, which is SNAPy's default (DetourR = 1.0).

First-time setup (once for this site)
  1. Pick or create a Google Cloud project and register it for Earth Engine (non-commercial use is free).
  2. In that project, enable the Earth Engine API.
  3. APIs & Services → OAuth consent screen: choose External and add your Google account as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add , and under Authorized redirect URIs add (for “Sign in without pop-up”).
  5. Paste the client ID and the project ID above and sign in. Other people can use the same IDs if you give their Google accounts access to the project.
